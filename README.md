# Compêndios para T20

Este módulo adiciona compêndios para o sistema **Tormenta20** no **Foundry VTT**.

## Conteúdo

- Ameaças (Atores)
- Itens
- Macros
- Tabelas (RollTables)
- Diários (Journal Entries)
- Playlist

## Instalação

Instale via Foundry (Add-on Modules) usando o Manifest URL:

```
https://github.com/sitariom/compendios-para-t20/releases/latest/download/module.json
```

## Compatibilidade

- Foundry VTT: v12 (verificado), v13 (máximo)
- Sistema: tormenta20
