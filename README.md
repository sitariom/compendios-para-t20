# Compêndios para T20

Este módulo adiciona compêndios de Itens, Ameaças, Macros e Tabelas para o sistema Tormenta20 no Foundry VTT.

## Conteúdo

- **Ameaças T20**: Compêndio contendo fichas de ameaças e monstros.
- **Itens T20**: Compêndio com equipamentos, armas, armaduras e itens gerais.
- **Macros T20**: Macros utilitários para facilitar a jogabilidade.
- **Tabelas T20**: Tabelas de rolagem aleatória.

## Instalação

### Via Link de Manifesto (Recomendado)

1. Abra o Foundry VTT.
2. Vá para a aba **Add-on Modules**.
3. Clique em **Install Module**.
4. No campo "Manifest URL", cole o seguinte link:
   `https://github.com/sitariom/compendios-para-t20/releases/latest/download/module.json`
5. Clique em **Install**.

### Manualmente

1. Baixe o arquivo `.zip` da última versão na aba "Releases" deste repositório.
2. Extraia o conteúdo na pasta `Data/modules/compendios-para-t20` do seu Foundry VTT.
3. Reinicie o Foundry VTT.

## Compatibilidade

Este módulo foi testado com o sistema Tormenta20 e Foundry VTT v12+.
